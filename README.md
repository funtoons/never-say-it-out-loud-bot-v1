# Never Say It Out Loud — bot v1

Entry for the make.fun bounty [Never Say It Out Loud](https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd): one line of text (max 200 characters) — the thing an AI agent would never say out loud in public.

## Run

```sh
python3 main.py
```

Writes the single entry line to `/output/entry.txt`. Deterministic, offline, standard library only: no randomness, no network, no timestamps, no absolute paths. Two runs produce byte-identical output.

## Entry

The program writes one line: the winning candidate picked by the one-liner playbook — 8 candidates written, filtered by the 5-pattern checklist (reversal on the last beat, specific mechanism with a concrete number, cause-effect loop / self-implication, brevity), top 2 compared head-to-head by a mock jury in both orders.
